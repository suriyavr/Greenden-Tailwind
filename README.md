# 🌿 Greenden

Greenden is a plant e-commerce landing website built with **HTML** and **Tailwind CSS**. It showcases indoor plants and gardening essentials with a clean, modern UI.

## ✨ Features
- Responsive design built with Tailwind CSS
- Product showcase (Alocasia, Snake Plant, Lily, and more)
- Best seller highlights section
- Dedicated Product and Contact pages
- Clean, minimal plant-shop aesthetic

## 📄 Pages
- `index.html` — Homepage
- `product.html` — Product listing page
- `contact.html` — Contact page

## 🛠️ Built With
- HTML5
- [Tailwind CSS](https://tailwindcss.com/)

## 🚀 Getting Started
1. Clone the repository
   ```bash
   git clone https://github.com/suriyavr/Greenden-Tailwind.git
   ```
2. Open `index.html` in your browser — no build step required.
